# 디자인 복원 안내

사용자 선호에 따라 이전 버전의 테마, 글자 크기, 사이드바 아이콘, 홈, 목록, 설정 배치를 복원했다.
앱은 이전처럼 내 실수 화면에서 시작한다. 새 대형 대시보드와 홍보형 제목은 제거했다.
보드 방향, 복습 일정, 대안 수, 변형 재생, PGN 식별, 학습 기록 등 기능 수정은 유지한다.

아래는 기능 개선의 상세 기록이며, 신규 홈/목록의 시각적 재설계는 현재 적용되지 않는다.

# 체스 오답노트 학습 개선

## 학습 흐름

- 앱은 오늘의 학습에서 시작한다. 복습 시간이 된 실수와 처음 보는 실수를 최대 10개씩 푼다.
- 정규 복습에는 미래에 예약된 문제가 포함되지 않는다. 실수 목록의 대국·등급·오답 필터가 실제 세션에도 적용된다.
- 목록의 정답은 기본적으로 숨긴다. 해설을 먼저 펼친 항목은 같은 목록 세션에서 연습으로 취급해 복습 일정을 변경하지 않는다.
- 정답/공개 뒤에는 설명을 직접 읽고 다음 문제를 누른다. 내 수와 상대 응수, 추천 변형을 한 수씩 재생할 수 있다.
- 정답 공개 후 따라 두는 연습은 오답 기록이나 10분 재학습 일정을 덮어쓰지 않는다.
- 기보 재현은 과거 수를 재현하는 훈련임을 명시한다. 실수 집중 복습은 mistakes의 추천 수를 찾는다.

## 분석

새 대국 분석은 Stockfish MultiPV 3을 사용한다. 일반 평가에서 최선수와 0.25 평가 폰 이내인 후보를 대안으로 저장하고, 강제 메이트를 유지하는 후보도 인정한다. 이 허용은 저장한 후보에 한정되며 모든 합법 수를 실시간 평가하는 것은 아니다.

추천 변형과 내 수 이후 상대 변형을 최대 8반수 저장한다. 메이트 전후 정보는 별도로 저장해 일반 손실 수치와 구분한다. 기존 기록의 큰 손실값은 메이트 관련 구기록으로 표시하며, 오래된 실수의 전체 변형과 대안 수를 자동으로 재분석하지는 않는다. 구기록은 저장된 내 수와 상대 응수까지 재생할 수 있다.

## 기록 호환성

SQLite에는 기존 행을 삭제하지 않고 추가 컬럼 및 review_events 테이블을 만든다. 새 통계의 최근 30일 첫 시도 성공률은 업데이트 이후 이벤트 기준이다. 기존 누적 기록은 보존한다.

고유 chess.com 게임 링크가 있는 대국의 기존 ID는 유지한다. 링크 없는 PGN은 시작 FEN과 수순도 식별에 사용한다. 기존 ID는 저장된 기보 문제들이 현재 PGN과 일치하는 경우에만 이관한다.

노테이션 1단계는 최소 30정답, 80% 정확도, 모든 기물의 양방향 성공을 요구한다. 예전의 통과 표시가 이 기준을 만족하지 않으면 보완 학습이 필요하지만 정오 기록은 지우지 않는다. 3단계 문제 ID는 FEN을 포함하므로 같은 SAN의 다른 국면을 덮어쓰지 않는다.

## 검증

```powershell
python -m unittest discover -s tests -v
python main.py --selftest
```

회귀 테스트는 임시 DB를 만들고 실제 학습 기록을 수정하지 않는다. 실제 Stockfish를 통한 PGN→실수 추출과 기존 실행본 DB 복사본의 호환성도 별도로 확인했다.

Google Drive OAuth와 rclone의 실제 외부 연결은 이번 검증 범위에 포함되지 않는다. 가져오기 설정과 연결 코드는 유지했다.
